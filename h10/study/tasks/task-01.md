# Room Topics

## Request

Each room should have a topic or description that appears at the top of the chat window, similar to its name. Room creators and administrators should be able to set or edit this topic. The topic should be visible to everyone in the room and persist until changed.

## Acceptance Criteria

- Each room's page shows a "Topic" field or section near the room name
- Room creators and administrators see an "Edit topic" button or field
- Other people in the room see the topic text but not an edit button
- Topics can contain multiple lines of text
- Existing rooms show no topic until one is set
- When a topic is changed, all people in the room see the new version immediately
- The topic text is stored and survives if a person leaves and rejoins the room
