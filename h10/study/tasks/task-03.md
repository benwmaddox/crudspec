# Starred Messages

## Request

Users should be able to star or bookmark important messages for their own reference. Starred messages are personal to each user and are not visible to others. Users can view a list of all their starred messages across all rooms, searchable by room and date.

## Acceptance Criteria

- Each message shows a "Star" icon or button that toggles on click
- When starred, the icon is filled or highlighted, showing the message is saved
- Users see a "Starred messages" section or page in the app navigation
- Starred messages are listed with the room name, date, author, and message text
- Users can search or filter starred messages by room name
- Starred messages list includes a link to jump to the original message in its room
- Starring a message does not affect other users; only the person who starred it sees it starred
- Existing messages show an empty/unfilled star icon
